# 组会报告网页版（2026-11-29）

八月以来三块工作的汇报页：跨模态舰船重识别的横向复现、流式新增样本下的持续重识别、
增量目标检测的科研与软件。左侧导航，单页长滚动；流程图与曲线都是手写 SVG，可交互。

- 纯静态，零外部请求（无 CDN、无字体外链），离线可打开。
- 页面里每个数字都带出处（文件与行号），出处指向生成它的私有研究仓库。
- 真源是私有仓库里的 `gen_data.py`：它从原始 CSV 现算出 `data.js`，并带 `--check`
  回源核验。本仓库只是它的发布副本，不要直接改这里的文件。

本地看：

    python3 -m http.server 8000     # 然后打开 http://127.0.0.1:8000
